# University Library Portal

A university library discovery-and-access platform (NestJS / Prisma / PostgreSQL), aimed at modeling heterogeneous resource access contracts rather than operating a circulation desk.

## Status

**Deployment and making the application fully functional are postponed.**

A design miss in the current approach means the system needs a **serious rebuild** before it can be productized or deployed as a working end-to-end application. Phased backend work and design docs remain in the repo as a learning / modeling baseline, not as a shippable product.

For the previous project overview, phase history, and local-dev notes, see [`docs/project-overview.md`](docs/project-overview.md). Full documentation index: [`docs/README.md`](docs/README.md).
